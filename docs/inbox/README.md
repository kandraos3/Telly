# Inbox: raw owner input

The owner's voice notes, brain dumps and review notes, saved **verbatim** by the `intake` skill (see [`docs/process/WORKFLOW.md`](../process/WORKFLOW.md)). Each file ends with a **Filed as** list linking the issues it produced. Files are never edited after filing, except to add links.

Name: `YYYY-MM-DD-<short-slug>.md`.
